# Meu Portfólio Pessoal

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e experiências como desenvolvedor. A aplicação é uma Single Page Application (SPA) rápida, responsiva e com um design moderno.

---

## 🚀 Funcionalidades

* Exibição dinâmica de projetos com suporte a vídeos e imagens.
* Roteamento suave e navegação fluida entre páginas de detalhes.
* Formulário de contato funcional integrado com backend para envio de e-mails reais.
* Interface 100% responsiva (adaptável para celulares, tablets e desktops).

---

## 🛠️ Tecnologias Utilizadas

**Frontend:**
* React
* TypeScript
* Tailwind CSS
* Vite
* React Router Dom
* Lucide React (Ícones)

**Backend (Microserviço de Contato):**
* Python
* Flask
* SMTPLib (Envio de e-mails)
